# Data Availability Statement

The validated H1 dataset used for the 32,000 sample atlas is sourced from the 
LIGO Open Science Center (GWOSC). 

- **Primary Source:** https://gwosc.org/
- **Dataset:** O3/O4 Bulk Data (H1 / L1)
- **Validation Labels:** Gravity Spy (LIGO-T1900000)

To reproduce the full validation, data must be placed in the /data directory 
following the naming convention established in scripts/run_full_h1_pipeline.py.
